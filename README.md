# ORION NEXUS IA

Página web de ORION NEXUS IA, la línea de inteligencia artificial para negocios de Orion Nova Technologies.

- `index.html`: la página completa (HTML, estilos y código en un solo archivo; funciona en celular y en computador).
- NOVA, el humanoide, atiende el chat de la página y habla con la voz del navegador.
- El login usa la misma cuenta de Orion Nova, ORION CORE y NOVA Restaurantes (Supabase).
- Se publica con GitHub Pages desde la rama `main`.
